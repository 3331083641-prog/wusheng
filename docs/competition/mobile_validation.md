# 手机实机最终验证

最终版请核对美的 KFR-35GW/N8KS1-1U、飞利浦 HX6850 和银色 TR-2001 的最新主图。十件 Demo 都有主图，三组资料已替换。三份新增 PDF 由用户确认绑定并保存在本地；公开仓库不附厂商全文。合成购买资料不是真实凭证。

最终版状态：**Awaiting physical-device verification**。用户提供的旧版实机截图确认基础 LAN 扫码可打开档案；新增图片链路、移动布局和 PDF 功能仍需重新实测。Codex 的 LAN HTTP、二维码 PNG 解码及浏览器只读测试不等于真实手机测试。本表只允许用户实测后填写结果。不公开用户提供的原始手机截图。

1. 电脑运行 `powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1`（已默认支持安全 LAN 分享，无需另开模式）。
2. 手机与电脑连接**可互通的同一局域网**（通常同一 Wi-Fi）；避免启用访客/客户端隔离，关闭会阻断 LAN 的 VPN。电脑保持运行。
3. 在电脑二维码面板点“重新检测网络”，确认 WLAN/物理网卡地址；换 Wi-Fi 后重新生成二维码。手机访问脚本输出的 `http://<LAN-IP>:8000`。电脑管理页面使用 `http://127.0.0.1:8000`。
4. 电脑打开美的空调、飞利浦牙刷或行李箱详情。添加一份无私人信息的测试 PDF，检查“分享内容预览”，选择默认 **7 天**。开启“允许查看所选说明书 PDF”，仅勾选这份文件；下载与持续授权分别决定，默认关闭。生成二维码。
5. 手机扫码，打开只读档案。
6. 确认当前物品高清图片、名称、型号、保修、真实生命周期与耗材正常；再检查 MacBook、耳机及自有物品照片。确认完整序列号、票据、未授权价格/渠道/位置/备注不出现。
7. 打开“在线查看”。微信内置浏览器若不支持 PDF，请用系统浏览器打开；允许下载时检查原文件名。未授权说明书不应有阅读入口。在线阅读内容可被保存，请勿授权含隐私的 PDF。
8. 电脑修改名称、维护或耗材，手机刷新应更新。上传另一份 PDF：未开持续授权则保持私有；已开持续授权则刷新后出现。删除授权 PDF 后，手机刷新列表及访问旧 PDF 链接均应失效。
9. 电脑撤销二维码，手机刷新应显示“分享已过期或已撤销”，旧 PDF 阅读/下载链接也应失效。再生成新码，确认旧码仍无效；已保存的副本无法收回。

无法访问时：核对 LAN IP、多网卡、可互通局域网、Windows 私人网络、防火墙允许 Python 及路由器客户端隔离。手机的 localhost 指向手机，不是电脑。本项目脚本不会修改防火墙，不要求管理员权限。更换端口或 IP 后需使用对应地址并重新下载二维码。

这是 LAN 服务，不是公网永久链接。7 天是令牌期限，并不保证电脑关机、停服或手机换网络后仍能访问。
