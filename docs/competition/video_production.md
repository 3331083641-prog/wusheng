## 双层 AI 与制作工具

默认 EvidenceProvider 是基于本地物品档案的规则与证据处理，不是 Qwen 大模型。录像中的规则请求真实返回并显示来源。可选增强采用本机已有 `qwen3-vl:4b-instruct-q4_K_M`，通过项目原有 Ollama Provider 和当前物品 ContextBuilder 调用，不下载新模型、不强制升级；最终模型镜头以实际响应中的 `activeProvider`、`modelInvoked` 和模型名称留证。模型失败时显示真实回退，不能把规则文字剪成模型成功。

采用 Playwright 进行实际点击、输入、上传与 WebM 录制；Remotion 4.0.532 负责 React 时间轴、柔和转场、焦点缩放、双画面与字幕；FFmpeg 负责章节剪辑、音轨、编码与 QA。Recordly / OpenScreen 仅参考鼠标焦点、轻柔缩放和镜头平移方法，没有复制其代码或光标素材。Remotion 使用其专有许可，不标作 MIT。工具与许可一手来源见 [规则及工具报告](../../video-production/reports/rules_review.md)。

制作使用 remotion-best-practices、remotion-create、remotion-markup、remotion-captions、remotion-render 与 remotion-studio 的实际工作流，以最终制作记录为准。RapidOCR、Qwen、React、FastAPI、Remotion、Playwright 和 FFmpeg 均为采用的第三方技术；物生自主实现的价值在资料关系、生命周期、耗材预测、来源追溯、物品级上下文与本地管理闭环。

中文旁白是 `zh-CN-XiaoxiaoNeural` 合成语音，非真人录音，未使用付费 API 或密钥。九章共 946 个汉字，整片约 **195.7 字/分钟**。47 句字幕来自实际合成句边界，并修正了服务返回的约 50ms 重叠；全文与旁白稿一致，均处于对应章节内，最多两行。旁白约 −18 LUFS，原创背景音乐约 −34 LUFS，音乐不盖住讲解。音乐使用独立合成脚本，无外部录音采样或现有旋律，[原创音乐与声音声明](../../video-production/licenses/MUSIC_LICENSE.md)保存 CC0 授权范围。

## 复现与分发范围

公开部分保留分镜、字幕、Remotion 源码、音频生成源码、许可与脱敏报告；大媒体、依赖、运行数据库、用户素材和原始接口响应由 `.gitignore` 排除。冷克隆复现者需提供自己的授权素材与真实录屏，不能期待公开仓库附带厂商说明书、私人订单或模型权重。

编辑和渲染步骤见 [视频工程说明](../../video-production/README.md)与 [Remotion 说明](../../video-production/remotion/README.md)。本地原始操作证据保存在 `video-production/reports/capture-*-raw.json` 与 `recordings/raw/`；音频生成证据保存在 `reports/voice-audio-qa.json` 与 `audio/voice-provenance.json`，这些仅本地文件不作为公开链接。

手机与电脑需处于可互通的同一局域网，电脑保持物生服务运行。团队已经确认基础手机扫码可用；本次仍需要一段 **12—18 秒**的真实手机录屏，包含打开当前扫码结果、照片出现和慢慢滚动只读信息。补录后替换第七章，并同步更新镜头标签、旁白、SRT、成片和 QA；补录前不能宣称真实手机录像这一项通过。
